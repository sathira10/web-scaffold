## Writing

For docs, commit messages, code comments and site copy.

- Write short sentences a person would say.
- Leave out filler adjectives (powerful, seamless, robust, effortless), em-dash asides, a bold
  lead-in on every bullet, and closing summaries.
- Say each fact once and link to it from elsewhere.
- Don't explain in prose what a check already enforces. Put the reason in a comment next to the
  check.
- Never invent facts, numbers, quotes or testimonials.
