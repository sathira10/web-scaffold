# Plans

Plans and specs for __NAME__. The repo holds the state of the work: the plan file says where a
piece of work stands, not anyone's memory of it.

- `00-brief.md`: who it's for, what it must do, what's out.
- `OPEN-ITEMS.md`: facts and assets still to come. A page leaves a claim out until its item is
  resolved.
- `TEMPLATE.md`: copy it to `NN-<slice>.md` for each piece of work.
